Mapa de Fontes do Golf-FPG

Todos os endereços que o site conhece, da FPG aos circuitos lá fora: o que cada um devolve, se precisa de login e um exemplo real para abrir. Escolha na barra o clube, o nº de federado, o torneio e a volta (por omissão: Santo da Serra, o Manuel e o V Aberto CGSS, volta 1). Os links saem já montados para eles: a parte preenchida fica a verde e aparece o botão Abrir. No campo Torneio, a lista mostra os últimos torneios conhecidos do clube. O que fica a amarelo é para substituir à mão.

A app golf-fpg — como fazer

Receitas para manter o site golf-fpg.vercel.app: onde está cada coisa, o que mudar e o comando a correr. Os comandos correm-se na pasta C:\golf-fpg. Regra do projecto: nada fica feito sem npm test e npm run build a passar.
